# إعداد Mobile 9.1 — إصدار Android سريع للنشر على GitHub Pages

## ما يجب فعله أولاً
**خذ نسخة احتياطية JSON من تطبيقك الحالي** عن طريق: «المزيد» > «نسخة احتياطية». لا تحذف بيانات Chrome ولا النسخة القديمة قبل التحقق من النسخة الجديدة.

## تحديث موقع GitHub Pages الموجود
1. افتح مستودعك: https://github.com/attest313/idad-mobile
2. حمّل هذا الملف ZIP على الحاسوب ثم اختر Extract All.
3. افتح مجلد IDAD_9_1_GitHub_Pages المستخرج. ارفع **محتوياته** إلى جذر المستودع (وليس المجلد نفسه أو ملف ZIP).
4. عبر GitHub، اختر Add file > Upload files. عند ظهور الملفات الموجودة بالأسماء نفسها، وافق على استبدالها ثم Commit changes.
5. انتظر النشر عبر Actions أو Settings > Pages. افتح https://attest313.github.io/idad-mobile/
6. أغلق نافذة التطبيق المثبت على Android بالكامل وافتحه مجدداً. قد تحتاج فتح الموقع في Chrome مرة ثانية حتى يحدث Service Worker؛ تحقّق من ظهور «إعداد 9.1».
7. إذا استمرت النسخة القديمة، انتظر دقيقة مع اتصال الإنترنت ثم أغلق التطبيق وأعد فتحه. **لا تختَر مسح بيانات الموقع/التطبيق**؛ ذلك قد يحذف سجلات الطلبة. استخدم نسخة JSON المحفوظة عند الحاجة.

## التحسينات
- تقسيم الجداول إلى 24 طالباً في الصفحة، مع استمرار تصدير كل السجلات.
- ترابط درجات/غياب محسن بفهرسة مؤقتة داخل الذاكرة. طريقة حساب الدرجات لم تتغير.
- عدم إعادة رسم سجل الغياب كله عند تغيير حالة طالب.
- البحث يتوقف 220 مللي ثانية قبل تحديث القائمة بدلاً من إعادة البناء لكل حرف.
- تجميع عمليات حفظ الدرجات والغياب بفاصل قصير، وحفظ فوري عند مغادرة الصفحة أو إخفاء التطبيق.
- Service Worker بتخزين محلي أسرع لملفات الواجهة.
- لا يضم هذا الإصدار أي بيانات طلبة؛ بياناتك الموجودة محفوظة في Chrome لنطاق GitHub Pages نفسه.

## القيود
- الحزمة PWA، وليست APK أصلياً.
- تم التحقق من محرك الدرجات بـاختبارات Node وبحالة تجريبية تضم 360 طالباً، 24 اختباراً، 1800 سجلاً للحضور، لكن لم يتم اختبار تفاعل مستخدم على هاتف Android فعلي في هذه البيئة.
- البطء الذي يحدث بسبب مساحة تخزين الهاتف أو ذاكرته أو حسابات أخرى قد يتطلب تحسينات إضافية حسب الجهاز.
- التخزين المحلي ليس بديلاً عن النسخ الاحتياطي المنتظم، ولا يوجد تزامن بين الأجهزة.
