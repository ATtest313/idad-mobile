# إعداد 9.2 — تحديث سلاسة التمرير على Android

هذا تحديث للإصدار 9.1، ولا يغيّر معادلات الدرجات أو عدد الاختبارات أو سجلات الطلبة.

## ماذا تغير؟
- إزالة `content-visibility:auto` عن صفوف الجداول؛ لأن الصفوف مقسمة إلى صفحات بالفعل (24 طالباً)، ولأن تقدير ارتفاعها قد يسبب قفزات أثناء السحب.
- إصلاح `overflow-x:hidden` على `html` و`body` الذي قد ينشئ حاويات تمرير إضافية؛ يستخدم الآن `overflow-x:clip` دون التسبب في تمرير عمودي متداخل.
- إزالة شريط العنوان الثابت أثناء التمرير على الهاتف، وتخفيف ظلال البطاقات والرسومات الزخرفية لتقليل عمليات إعادة الرسم.
- إضافة زرين يظهران في الصفحات الطويلة فقط، للوصول إلى أعلى الصفحة أو أسفلها مباشرة.
- تحديث رقم الإصدار إلى 9.2 وتحديث Service Worker؛ أثناء اتصال الإنترنت يتحقق من الصفحة ثم يعود إلى الكاش عند انقطاعه.

## التحديث إلى GitHub Pages
1. خذ نسخة احتياطية JSON من إعداد 9.1 قبل تحديث الملفات.
2. افتح المستودع: https://github.com/attest313/idad-mobile
3. فك ضغط الحزمة وارفع **محتويات** مجلد `IDAD_9_2_Android_Smooth_Scroll` إلى جذر المستودع واستبدل الملفات المطابقة عبر Commit changes.
4. انتظر انتهاء GitHub Pages من النشر. ثم افتح في Chrome: https://attest313.github.io/idad-mobile/?release=9.2
5. ينبغي أن يظهر «إعداد 9.2». أغلق التطبيق المثبت وافتحه مرة أخرى بعد وصول التحديث. لا تمسح بيانات التطبيق أو Chrome.

## التحقق والقيود
- جرى فحص بنية ملفات الحزمة وصحة شيفرة JavaScript وقواعد الأنماط.
- لم يجر اختبار حركة تمرير فعلية على هاتف Android؛ النجاح يتوقف على طراز الهاتف والمتصفح والبيانات المخزنة.
- يحتفظ التطبيق بمعرف PWA الأصلي ومفتاح التخزين المحلي كما هو، حتى لا يتعامل معه Android كتطبيق جديد ولا يفقد المستخدم الوصول إلى سجلاته.
- التطبيق لا يزال PWA؛ لا توجد مزامنة آلية بين الأجهزة.
