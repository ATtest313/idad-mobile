# إعداد 9.0 — تطبيق الهاتف

## ما يتضمنه الإصدار
- تطبيق ويب قابل للتثبيت (PWA) على Android وiPhone من استضافة HTTPS.
- تصميم متجاوب للهاتف وواجهة عربية RTL مع شريط تنقل من ست أدوات.
- يحافظ على نفس محرك الدرجات والفترات والفصل العملي والنظري والغياب والاختبارات الموجود في إعداد 8.1.
- استيراد أسماء الطلبة من XLSX/XLSM/CSV باستخدام ملفات الهاتف مع معاينة قبل الإضافة.
- نسخ احتياطي بصيغة JSON واستيراد النسخة من Windows؛ وتصدير كشف درجات CSV.
- حفظ محلي والتشغيل دون إنترنت **بعد فتح الموقع على HTTPS وتحميل الملفات للمرة الأولى**.
- وضع الهاتف لا يحتاج لخادم Windows أو Python بعد التثبيت.
- إدخال صوتي عندما يدعمه المتصفح والجهاز؛ قد يتطلب اتصالاً بالإنترنت.

## التثبيت الصحيح على الهاتف
1. ارفع الملفات الموجودة في هذه الحزمة **كما هي** إلى استضافة HTTPS ثابتة، بحيث يصبح `index.html` في جذر الموقع (مثل Netlify Drop أو GitHub Pages). لا ترفع `IDAD_Offline_Standalone.html` بدل index.html.
2. افتح رابط الموقع من الهاتف، وانتظر اكتمال التحميل الأول.
3. Android: من Chrome افتح ⋮ ثم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية». iPhone: افتح Safari ثم مشاركة > «إضافة إلى الشاشة الرئيسية».
4. افتح الأيقونة التي ظهرت على الهاتف. ادخل إلى «المزيد» ثم «فحص جاهزية العمل دون إنترنت» للتحقق.
5. لن تنتقل بيانات Windows آلياً: في Windows اختر نسخ احتياطي JSON؛ انقل الملف للهاتف؛ داخل الهاتف افتح «المزيد» > «استعادة JSON».

## ملاحظات وحماية بيانات الطلبة
- التطبيق يخزن بيانات كل هاتف على حدة، ولا ينشئ حسابات مستخدمين أو مزامنة سحابية.
- حذف بيانات الموقع أو تغيير الهاتف دون نسخ احتياطي قد يفقد السجلات نهائياً.
- لا ترسل نسخاً احتياطية فيها بيانات طلبة إلا ضمن إجراءات المؤسسة وسياسة الخصوصية.
- استيراد Excel مخصص لأسماء الطلبة، وليس استنساخ جميع معادلات الملف.
- قد يحتاج استيراد XLSM إلى متصفح حديث يدعم DecompressionStream؛ استخدم CSV عند عدم التوافق.
- طباعة الدروس من الهاتف تعتمد على دعم نافذة الطباعة بالمتصفح.
- الملف `IDAD_Offline_Standalone.html` للتجربة المحلية فقط، ولا ينشئ تثبيت PWA ولا يُنصح باستخدامه لتخزين السجلات المهمة.

## حالة الاختبار
تم اختبار محرك الحساب وواجهاته من خلال اختبارات Node، ومحاكاة شاشة Android صغيرة في Chromium تتضمن إضافة شعبة وأسماء ودرجة ورفض علامة خارج المجال. تعذّر اختبار PWA في بيئة HTTPS الفعلية، أو اختبار Safari على iPhone أو APK على جهاز Android حقيقي؛ يجب استكمالها قبل النشر التجاري.
